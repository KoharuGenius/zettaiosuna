## 絶対押すな
- ティラノスクリプトにGeminiが吐き出したhtml+CSS+JavaScriptを組み込む実験

## 素材
- ティラノスクリプトにサンプルとして入っている背景および立ち絵（あかね）を使用する

## ルール
- あかねが仕掛けたボタンを押せたら主人公の勝ち
- あかねがボタンを押させないための努力が何かズレている
  - (例)「絶対押すな」と書いてあるなど
